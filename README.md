## 🎬 Key Interactive Features

1. **Full Red Color Palette Across Whole Website**:
   - Signature vibrant red backdrop (`#d00d17`, `#90050c`, `#500206`) with champagne gold accents (`#f6e297`, `#d4af37`) across all sections, background layers, and glass cards.

2. **3-Second "Something BIG is happening..." Black-Fade Intro**:
   - Dark intro screen with gold glowing text: **"Something BIG is happening..."** that black-fades after 3 seconds into the main site.

3. **Personalized Name Entry Popup & Greeting**:
   - Modal raises asking: *"Before we reveal the magic, who is joining our celebration?"*.
   - Dynamically greets the visitor: **"✨ Hi [NAME]! Welcome to our celebration ✨"**.

4. **Centerpiece Hero & Physics Rope**:
   - Image 1 (`hero-tug-couple.jpg`: Laxman & Abi) displayed full-width as the centerpiece hero with interactive SVG physics rope overlay.

5. **Interactive Celebration Photo Carousel**:
   - Slider displaying Image 2 (`hero-tug-group.jpg`: "WE ARE GETTING ENGAGED") and showcase slides with Previous/Next buttons, indicator dots, auto-play, and touch swipe.

6. **Digital Scratch-to-Reveal Card**:
   - HTML5 Canvas foil scratch card. Scratching off the golden foil reveals: ✨ **"You are invited to celebrate with us!"**.

7. **Global Click Grand Particle Shower**:
   - Clicking anywhere on the website spawns a golden sparkle/heart particle shower from the click coordinate.

8. **"Leave a Message" Guestbook Widget**:
   - Visitors can type and post warm wishes for Laxman & Abi. Messages are rendered on a guestbook message wall and saved in local storage.

9. **"🥂 Raise a Virtual Toast" Widget**:
   - Interactive button with live toast counter ("143 Toasts Raised!"), champagne particle shower, sound effect, and toast notification.

10. **Core Invitation Suite & Ambient Music**:
    - Live IST countdown timer targeting **21 October 2026, 6:30 PM IST** at **Eden Garden, Tirunelveli**.
    - Add to Calendar (.ics & Google Calendar), Google Maps, WhatsApp sharing, background music toggle (`♫`), desktop custom cursor, and 3-click ampersand easter egg.

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v18+)
- npm or yarn

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 3. Production Build & Preview
```bash
npm run build
npm run preview
```
